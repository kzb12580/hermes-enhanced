# PPT 动画添加说明

Hermes 为您创建了精美的 PPT 内文和页面切换效果。如需为文字、图片等元素添加入场/退出动画，请按以下步骤在 PowerPoint 中操作。

---

## 快速添加文字入场动画（最常用）

1. 打开 PPT 文件
2. 选中要添加动画的文字框
3. 点击顶部菜单 **动画** 选项卡
4. 在动画库中选择一个效果（推荐：**淡入**、**飞入**、**擦除**）
5. 在 **计时** 区域设置：
   - **开始**：选择「单击时」（点击一次出现一个）
   - **持续时间**：0.5 秒（快速）或 0.8 秒（优雅）
6. 对其他文字框重复操作

## 批量添加动画（效率技巧）

1. 在左侧幻灯片列表中，按住 **Ctrl** 选中多张幻灯片
2. 点击 **切换** 选项卡 → 选择一个切换效果（如「淡入」）
3. 点击 **全部应用** → 所有页面都用同一个切换效果

## 推荐动画组合

| 场景 | 入场动画 | 持续时间 | 触发方式 |
|------|---------|---------|---------|
| 标题 | 淡入 | 0.8s | 单击时 |
| 正文要点 | 擦除（自左侧） | 0.5s | 单击时 |
| 图片/图表 | 飞入（自底部） | 0.6s | 与上一动画同时 |
| 数据卡片 | 缩放 | 0.4s | 单击时 |

## 让所有文字逐条出现

1. 选中包含多个要点的文字框
2. **动画** → **淡入**
3. 点击 **效果选项** → 选择 **按段落**
4. 每次点击会依次出现一个要点

## 页面切换效果

1. 选中一张幻灯片
2. **切换** 选项卡 → 选择效果（推荐：淡入、推入、擦除）
3. 设置持续时间（1 秒左右最佳）
4. 点击 **全部应用**

---

> 💡 **提示**：动画不宜过多，每页 2-3 个动画效果即可。过多动画会分散注意力。
